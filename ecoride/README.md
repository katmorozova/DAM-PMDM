# EcoRide - Sistema de Gestión de Vehículos Compartidos

**EcoRide** es un sistema de consola desarrollado en **Dart** que simula el funcionamiento de una plataforma de movilidad urbana sostenible

### Características principales
* **Gestión de Flotas:** Control de estado de batería, disponibilidad y cálculo de tarifas según el tipo de vehículo (Patinetes y Coches).
* **Geolocalización:** Integración de posicionamiento GPS mediante *Mixins* y desestructuración con *Records* de Dart 3
* **Usuarios y Tarifas:** Lógica de reservas con descuentos para usuarios VIP y validación de saldo
* **POO Avanzada:** Implementación de polimorfismo, clases abstractas, pattern matching (`switch`) y manejo de excepciones

### Tecnologías utilizadas
* **Dart SDK** (v3.x)
